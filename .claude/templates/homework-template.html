Homework: Chapter Template

You've learned how declaring and dereferencing a pointer works. Now put it into practice: two parts, one for each idea, each a small complete program or function you write yourself in exercises/ — checked with make check-mine, not by reading this page.

exercises/01_declare_pointer.c

Declare an int variable, declare a pointer to it, and print the value through the pointer — not by naming the variable directly.

The chapter showed this with a variable named age in "Declaring a pointer" — do it again with a variable of your own.

Forgetting the & when you point at your variable is the most common first mistake here — without it, you are trying to store an int's value in a variable that expects an address, and the compiler refuses to compile it.

exercises/02_swap.c

Write a swap function that exchanges two int values using pointers, so the change is visible back in the code that called it.

This is what "Dereferencing a pointer" in the chapter was building toward — not just reading through a pointer, but writing through one. Work out how.

Stuck? Show one approach 
void swap(int *a, int *b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

This is one approach, not the answer. You could swap with arithmetic or with XOR — both work, and both are harder to read. Clear beats clever.
