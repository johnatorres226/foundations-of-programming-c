Homework: Chapter Template

You read how declaring and dereferencing a pointer works. This homework has two parts, one for each idea. Each one is a small, complete program or function you write yourself in exercises/, checked by make check-mine — not by reading this page.

exercises/01_declare_pointer.c

What it asks: declare an int variable, declare a pointer to it, and print the value through the pointer — not by naming the variable directly.

Why: this is the exact pattern from "Declaring a pointer" in the chapter, with your own variable name in place of age.

Forgetting the & when you point at your variable is the most common first mistake here — without it, you are trying to store an int's value in a variable that expects an address, and the compiler refuses to compile it.

exercises/02_swap.c

What it asks: write a swap function that exchanges two int values using pointers, so the change is visible back in the code that called it.

Why: this is what "Dereferencing a pointer" in the chapter was building toward — not only reading through a pointer, but writing through one too.

Stuck? Show one approach 
void swap(int *a, int *b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

This is one approach, not the answer. You could swap with arithmetic or with XOR — both work, and both are harder to read. Clear beats clever.
