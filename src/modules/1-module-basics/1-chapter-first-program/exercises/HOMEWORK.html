Homework: Your First Program

You read what each of the four pieces of hello.c does — the #include, main, printf, and return. This homework has three parts, each a complete program you write from scratch using that same shape. Nothing here is inlined for you to copy — write each file yourself in exercises/, and check your work with make check-mine, not by reading this page.

exercises/01_hello_world.c

What it asks: a complete program that prints exactly one line, the classic hello-world message, then exits successfully.

Why: this is the whole skeleton from the chapter in one file — the header you borrow, the one starting point, the line that does the printing, and the line that reports back. If you can write this one without looking anything up, you have the shape.

The test compares your output letter for letter, including the newline at the end. A printf call without a trailing \n will fail even if the visible words look identical — the missing newline is a real difference the test can see.

exercises/02_two_lines.c

What it asks: a complete program that prints two separate lines, using two separate printf calls.

Why: the chapter showed that statements run in the order they are written — this exercise is that idea, made real. Two calls, two lines, top to bottom.

Each printf call needs its own \n. Forgetting the first one runs both lines together on the same line of output — the program still compiles and runs, it doesn't produce two separate lines.

exercises/03_quoted_message.c

What it asks: a complete program that prints one line containing its own double quotation marks — for example, someone's quoted words inside the message.

Why: this is the escaped-quote gotcha from the chapter: a bare " in the middle of a string literal ends the string early, so you need \" wherever a real double quote belongs inside your message.

Stuck? Show one approach 
#include <stdio.h>

int main(void) {
    printf("She said \"hello\" back.\n");
    return 0;
}

This is one approach, not the answer. Any message with an escaped \" in the right place passes — the exact words you print don't have to match this example, only the shape of the escape.

Check all three with make check-mine. To check only this chapter, run make check-mine CHAPTER=1-module-basics/1-chapter-first-program.
