Homework: Your First Program

You've learned what each of the four pieces of hello.c does — the #include, main, printf, and return. Now put it into practice: three complete programs, written from scratch in exercises/ and checked with make check-mine — not by reading this page.

exercises/01_hello_world.c

Write a complete program that prints one line — the classic hello-world greeting — then exits successfully. Build the whole skeleton yourself: the header you borrow, the one starting point, the line that does the printing, and the line that reports back.

If you can put all four pieces down without looking anything up, you have the shape.

The test compares your output letter for letter, including the newline at the end. A printf call without a trailing \n will fail even if the visible words look identical — the missing newline is a real difference the test can see.

exercises/02_two_lines.c

Write a program that prints two separate lines of output, using two separate printf calls.

The chapter showed that statements run in the order they are written — prove it to yourself. Two calls, two lines, top to bottom.

Each printf call needs its own \n. Forgetting the first one runs both lines together on the same line of output — the program still compiles and runs, it doesn't produce two separate lines.

exercises/03_quoted_message.c

Write a program that prints one line containing its own double quotation marks — say, someone's quoted words inside the message.

There's a trap here: a bare " in the middle of a string literal ends the string early. Work out how to get a real double quote into your output anyway — the chapter's printf section has the piece you need.

Stuck? Show one approach 
#include <stdio.h>

int main(void) {
    printf("She said \"hello\" back.\n");
    return 0;
}

This is one approach, not the answer. Any message with an escaped \" in the right place passes — the exact words you print don't have to match this example, only the shape of the escape.

Check all three with make check-mine. To check only this chapter, run make check-mine CHAPTER=1-module-basics/1-chapter-first-program.
