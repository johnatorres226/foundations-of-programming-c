Homework: Making Decisions

You've read how if, else, and else if choose between paths, and how C decides true from false using nothing but zero and nonzero. Now put it into practice: four small functions, written from scratch in exercises/ and checked with make check-mine — not by reading this page.

exercises/01_classify_sign.c

Write a function int classify_sign(int n) that returns -1 when n is negative, 0 when n is exactly zero, and 1 when n is positive.

The chapter's "else if — chaining more questions" section built a three-way chain out of a grade. Work out the same shape here, with three conditions instead of four.

Zero is neither negative nor positive — it needs its own branch. A chain that only checks n < 0 and falls back to 1 for everything else will return 1 for n = 0, which the test does not accept.

exercises/02_max_of_three.c

Write a function int max_of_three(int a, int b, int c) that returns whichever of the three is largest. If two or more are tied for largest, return that shared value.

You do not have && yet — that arrives next chapter. The chapter's "else — the other path" section showed if/else nesting inside each other. Work out how to find the largest of three values by nesting one comparison inside another, two levels deep, instead of combining conditions into one line.

Compare a and b first, keep only the winner, then compare that winner against c. Trying to compare all three at once in a single condition is exactly the tangle next chapter's && exists to untangle — for now, nest two simple decisions instead of writing one complicated one.

exercises/03_truthy.c

Write a function int is_truthy(int n) that returns 1 if C's own if would treat n as true, and 0 if it would treat n as false — for any int, including negative ones.

The chapter's "Zero is false, everything else is true" section is the entire content of this exercise. Prove to yourself that you do not need a comparison operator anywhere in this function at all — the parameter itself is already the condition.

Stuck? Show one approach 
int is_truthy(int n) {
    if (n) {
        return 1;
    } else {
        return 0;
    }
}

This is one approach, not the answer. Writing n directly as the condition, with no == 0 or != 0 anywhere, is the whole point — it is the same test C's own if runs on any condition you give it.

exercises/04_grade_letter.c

Write a function char grade_letter(int score) that returns 'A' for a score of 90 or above, 'B' for 80 or above, 'C' for 70 or above, 'D' for 60 or above, and 'F' for anything below that.

The chapter's "Two traps: branch order and = vs ==" section showed exactly what goes wrong when a chain like this is ordered loosest-first. Write your chain narrowest condition first, and prove to yourself with a boundary score — try 90 itself, not only 95 — that each cutoff lands on the letter you meant.

The test checks the exact boundaries: 90, 80, 70, and 60 each belong to the higher letter, not the lower one. Using > where the chapter's example used >= shifts every one of those four scores to the wrong grade.
