# Changelog

All notable changes to this course are documented here.
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Versioning is [Semantic Versioning](https://semver.org/), interpreted for a curriculum:

| Bump | Means |
|---|---|
| **MAJOR** | Curriculum restructure. Modules renumbered — learner bookmarks and links break. |
| **MINOR** | A new chapter or module ships. |
| **PATCH** | Corrections, typos, fixed links, clarified wording. |

**v1.0.0 = all 15 modules complete.** Everything before that is `0.x` and explicitly
in progress.
